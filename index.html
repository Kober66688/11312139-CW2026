02 / FUNDAMENTALS

對數基本性質與運算法則

輸入數值，即時比較等式兩邊。先檢查真數與底數條件，再使用公式。

● 動態驗算

運算法則測試台

預設 b = 2、x = 8、y = 4、r = 3、c = 10；可自由修改。

兩個特殊值與單調性

logb1 = 0

因為 b0 = 1。只要底數合法，這個式子一定成立。

logbb = 1

因為 b1 = b。對數與指數互為逆運算。

底數決定增減性

當 b > 1 時，logbx 在 x > 0 上遞增；當 0 < b < 1 時則遞減。

使用公式前必須先檢查

底數 b、c 必須大於 0 且不等於 1；log 裡面的真數必須大於 0。

常見錯誤：logb(x + y) 一般 不等於 logbx + logby。乘法才能拆成加法。

指數 ↔ 對數

bt = x ⇔ logbx = t

相同底數之下，兩種寫法互相轉換。

對數與乘除

乘法轉加法，除法轉減法；先確認各真數皆為正。

對數與次方

真數的次方可提出成係數；對所有實數 r，要求原始真數 x > 0。

03 / LOGARITHMIC EQUATIONS

從對數式到解方程

示範指數對數互換、移項、合併運算與驗根。包含容易產生增根的題型。

● 分步解題 · 定義域檢查

解題實驗台

CURRENT EQUATION

在這裡看解題結果。

對數式 ⇔ 指數式

log₂8 = 3 ⇔ 2³ = 8

解對數方程第一步，常常就是換成指數式。

解方程 SOP
① 列真數限制
② 用運算法則合併或化成指數式
③ 解代數方程
④ 代回原式驗根、刪除增根

課堂快問快答

01 / 必考

log2(x − 3) = 2，求 x。

x − 3 = 2² = 4，x = 7；且 7 > 3，符合定義域。
02 / 驗根

log2x + log2(x − 2) = 3，求 x。

x(x − 2) = 8，解得 x = 4 或 −2；原式要求 x > 2，因此只有 x = 4。
03 / 易錯觀念

log3(−9) 可以在實數範圍計算嗎？

不可以。實數對數的真數必須大於 0。
